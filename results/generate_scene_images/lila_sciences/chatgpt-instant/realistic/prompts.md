# Lila Sciences — ChatGPT scene prompts

ChatGPT (Instant), one chat. Paste message 1, then each scene prompt as its own message. Save each picture as `<qid>.png` in this folder.

## Message 1 — rules + anchor

```
I'm making memory-aid pictures for a flashcard story. All pictures share one character: a single LILAC. Keep this exact LILAC identical in every picture I ask for in this chat.

Style for every picture: photorealistic, natural light, real materials and textures. Every object I write in CAPITALS must be large, clear and easy to recognise; it is what the viewer has to remember. Make each scene striking or a little strange, because unusual images are easier to recall. No captions or labels; the only lettering allowed is lettering a scene itself describes, exactly as written there. Draw one picture per message and never combine two scenes; each picture gets its own full frame, with no borders or panels.

First picture: the LILAC alone, facing the viewer, as a character reference.
```
